# Деплой на Netlify

## Структура проєкту
```
index.html                      — сайт
netlify/functions/order.js      — приймає замовлення і шле в Telegram
api/order.js                    — те саме, але для Vercel (не потрібен, якщо деплоїте на Netlify)
netlify.toml                    — конфіг Netlify
.env                            — ваш токен і chat_id (НЕ комітити в git!)
```

## Кроки

1. **Зареєструйтесь на netlify.com**, якщо ще немає акаунта.

2. **Задеплойте проєкт** — найпростіше через drag-and-drop:
   - Зайдіть на https://app.netlify.com/drop
   - Перетягніть туди всю цю папку цілком
   - Сайт одразу опублікується, дасть вам посилання типу `random-name-123.netlify.app`

   (Або через Git: залийте папку в репозиторій на GitHub і підключіть його в Netlify — тоді кожен `git push` буде автоматично передеплоювати сайт.)

3. **Додайте змінні середовища** (це і є безпечне місце для токена):
   - Site settings → Environment variables → Add a variable
   - `TELEGRAM_BOT_TOKEN` = ваш токен бота
   - `TELEGRAM_CHAT_ID` = `8289789381`
   - Збережіть і зробіть **Redeploy** сайту (Deploys → Trigger deploy), щоб функція підхопила змінні.

4. **Перевірте**: відкрийте сайт, натисніть «Замовити» → заповніть форму → «Підтвердити замовлення». Повідомлення має прийти боту в Telegram за пару секунд.

## Локальне тестування (необов'язково)

Якщо хочете перевірити перед деплоєм:
```
npm install -g netlify-cli
netlify dev
```
Це підхопить `.env` автоматично і підніме сайт разом із функцією на localhost.

## Важливо

- **Токен більше ніде в коді немає** — тільки в `.env` і в змінних середовища Netlify. У браузері (`index.html`) його не видно.
- Не завантажуйте `.env` у публічний GitHub-репозиторій — він вже доданий у `.gitignore`.
- Токен, який ви використали, вже засвітився в чаті — рекомендую після перевірки все одно перевипустити його через **@BotFather → /mybots → API Token → Revoke current token**, і оновити значення в Netlify.
- Якщо деплоїте на **Vercel** замість Netlify — видаліть папку `netlify/` та `netlify.toml`, лишіть `api/order.js`, і в `index.html` замініть `ORDER_ENDPOINT` на `/api/order`. Змінні середовища задаються так само, в Project Settings → Environment Variables.
